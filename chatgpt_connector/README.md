# ChatGPT Connector add-on

Home Assistant OS add-on for the Home Assistant ChatGPT Connector.

This first version is read-only and uses the Supervisor-provided token internally. No long-lived Home Assistant token is stored in the repository or add-on configuration.

Tools:
- ha_health
- list_entities
- get_entity_state

The remote ChatGPT transport is intentionally not exposed yet. First install the add-on and verify local Home Assistant API access.
